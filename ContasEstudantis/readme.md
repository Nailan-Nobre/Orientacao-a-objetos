# Gestão Financeira de Contas Estudantis

## Sobre a atividade

Esta atividade propõe o desenvolvimento de um módulo de **Gestão Financeira de Contas Estudantis**, aplicando os conceitos de **encapsulamento da Programação Orientada a Objetos (POO)**.

## Objetivo

Gerenciar as informações dos alunos e suas respectivas contas estudantis, permitindo:

- o pagamento de mensalidades;
- o gerenciamento de créditos para o restaurante universitário.

## Conceitos abordados

- Encapsulamento;
- Classes e objetos;
- Atributos e métodos;
- Organização e manipulação de dados dos alunos e de suas contas.
